# Dự án Web - Khởi tạo nhanh

Hướng dẫn ngắn để bắt đầu phát triển:

- Mở `index.html` trong trình duyệt (double-click hoặc kéo thả vào cửa sổ trình duyệt).
- `style.css` đã có sẵn trong workspace — chỉnh sửa để thay đổi giao diện.
- `script.js` chứa ví dụ xử lý nút và hàm `showMessage()` để tái sử dụng.

Gợi ý tiếp theo:

- Muốn chạy server phát triển cục bộ (không cần backend), cài `live-server` hoặc dùng `python -m http.server`.
- Muốn tôi thêm cấu trúc thư mục (assets, components, pages), nói yêu cầu cụ thể.
